# RelaxKonOS 0.1.0 Preview

This is the first public preview of RelaxKonOS and of the new relaxkon.com website. It
introduces the desktop shell, the core built-in applications and the server-side
foundations that the rest of the product is built on.

## Highlights

- Desktop shell with window management, taskbar, start menu and modal dialogs
- Terminal with persistent remote PTY sessions over SignalR and a local fallback mode
- File manager executing all file operations through the server REST API with host OS permissions
- Built-in browser with bookmarks and history persisted per user
- Settings centre with multi-device workspace preference synchronisation
- Task manager with a 1 Hz performance stream and 60 seconds of history
- Docker, firewall, process guardian, certificate, web server, Git and tunnel management foundations
- New marketing website with documentation, downloads, releases and FAQ

## Notes

- Windows x64/x86_64 and ARM64, Linux x64 and ARM64, and macOS builds are being prepared.
- Download artifacts are not published yet. Availability will be announced on the Downloads page.
- Some capabilities are marked as MVP and are being hardened for the next milestone.

## Known limitations

- Windows Server support for the firewall application is not available yet.
- Code editor multi-folder workspaces are still in progress.
- Health checks and native service adapters for the process guardian are under design.
