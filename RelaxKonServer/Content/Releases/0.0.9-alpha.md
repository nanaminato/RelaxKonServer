# RelaxKonOS 0.0.9 Alpha

An internal alpha focused on stability of the platform layer before the first public preview.

## Highlights

- Window manager rewrite with reliable z-order, resize and modal dialog ownership
- Application runtime finalised around `IRemoteApplication` and `RemoteApplicationBase`
- Authentication bridge for Windows LogonUser and Linux PAM + NSS
- Protocol assembly split into explicit REST and SignalR contracts
- SQLite persistence with incremental schema reconciliation
