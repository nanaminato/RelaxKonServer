# Welcome app

Welcome is the first application RelaxKonOS opens. It acts as both an introduction and a self-check.

## Overview

Welcome confirms that the application runtime, the window manager and the server connection are healthy, and points you at the next steps.

## Features

- Shows client and server connection status
- Verifies the application runtime and window manager
- Links to documentation, settings and sample applications

## How to use it

It opens automatically after sign-in. Close it and reopen it from the start menu whenever you like.
