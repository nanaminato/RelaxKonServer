# File Services

File Services manages installation and operation of host file sharing, starting with SMB.

## Goals

- Start, configure and recover services through managed tasks
- Use Samba on Linux and SMB Server on Windows
- Stay consistent with workspace preferences instead of per-machine configuration

## Status

The first SMB implementation is being designed and delivered; the long-term specification defines discovery, lifecycle and recovery.
