# Notepad

Notepad is a lightweight editor for plain text, built mainly to solve **cross-platform text encoding**.

## Features

- Open and save remote text files
- Multiple encodings: UTF-8, GBK, Shift-JIS and others
- Encoding dialog shared with the code editor
- Multiple windows

## How to use it

Open Notepad from the start menu and pick a server path with "open". If the detected encoding is wrong, choose the correct one in the encoding dialog and reload.
