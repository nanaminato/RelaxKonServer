# Image Viewer

Image Viewer displays common image formats stored on the server host.

## Features

- Opens PNG, JPEG and other common formats
- Zoom and scroll
- Multiple windows for several images

## How to use it

Open it from the start menu and pick an image path, or launch it from File Manager with "open with".

> The client renders the image; the server only reads the file bytes.
