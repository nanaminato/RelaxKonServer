# Image Viewer

Image Viewer displays common image formats stored on a RelaxKonOS Server host. In an SSH desktop, it can also open images from the confirmed SSH host through SFTP.

## Features

- Opens PNG, JPEG and other common formats
- Zoom and scroll
- Multiple windows for several images

## How to use it

Open it from the start menu and pick an image path, or launch it from File Manager with "open with". In an SSH desktop, open the image from the SSH File Browser.

> The client renders the image; the server only reads the file bytes.
