# Get to know the desktop and windows

These steps use the desktop client and a RelaxKonOS Server workspace. Availability depends on client and server versions, installation mode, and account permissions.

## 1. Open your first app

Click Start at the lower left and open File Manager. The directories belong to the server, and access depends on your account permissions.

![Screenshot: Open your first app](/assets/tutorials/en-US/tutorial-desktop-1.svg)

*Screenshot: Open your first app*

## 2. Arrange a window

Drag the title bar to move a window and its edges to resize it. Use the title-bar buttons to minimize, maximize, or close it. Restore a minimized window from the taskbar.

![Screenshot: Arrange a window](/assets/tutorials/en-US/tutorial-desktop-2.svg)

*Screenshot: Arrange a window*

## 3. Use two apps together

Keep File Manager open and launch Terminal from Start. Position both windows for easy viewing and switch with the taskbar. Most management apps use one window; Notepad and Code Editor support multiple windows.

![Screenshot: Use two apps together](/assets/tutorials/en-US/tutorial-desktop-3.svg)

*Screenshot: Use two apps together*

## 4. Personalize the desktop

Open Settings from Start and choose an available appearance or workspace preference. Confirm the result. Saved login credentials stay in secure storage on the device and do not sync with the workspace. See [Settings](/docs/en-US/latest/apps/settings).

![Screenshot: Personalize the desktop](/assets/tutorials/en-US/tutorial-desktop-4.svg)

*Screenshot: Personalize the desktop*
