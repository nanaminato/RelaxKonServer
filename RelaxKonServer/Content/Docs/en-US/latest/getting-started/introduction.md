# Welcome to RelaxKonOS

RelaxKonOS is a cross-platform workspace operating environment. Its client renders the desktop interface locally while the server manages workspace state, storage, runtime, and remote services.

> RelaxKonOS does not transmit desktop pixels. It synchronizes state and user intent.

Start with the architecture guide to understand the boundary between the client and server.
