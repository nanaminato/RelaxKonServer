# 永続化

サーバーは**2 つの SQLite ドメイン**を使用します。ユーザーとワークスペース単位で整理された業務データベースと、マシン固有のリソースを扱うホストグローバルデータベースです。

## 業務データベース

EF Core と SQLite を使用し、起動時に増分の `CREATE TABLE IF NOT EXISTS` 文で整合させます。

| 領域 | 内容 |
| --- | --- |
| アイデンティティ | ユーザー、デバイス、認証保護の状態、セキュリティイベント |
| ワークスペース | 設定、ターミナル設定、ブラウザー設定、ウィンドウレイアウト |
| アプリケーション状態 | ブックマーク、履歴、プライベートなキー／バリュー設定、画像ミラー |
| プラットフォームリソース | Git リポジトリ、トンネル定義、レジストリエントリ |

## ホストグローバルデータベース

**このマシン**に紐づくリソースを保持し、手書きのバージョン付きマイグレーター（v1〜v7）をトランザクション保証付きで使用します。

- 証明書と更新記録
- Web サーバーサイト、設定スナップショット、操作ログ

## インメモリ状態

一部の状態は、その意味が「永続データ」ではなく「現在の接続」であるため、意図的にメモリ上に留めます。

- セッションとリフレッシュトークン
- PTY プロセス

## 整合性の戦略

- スキーマ変更は追加のみで、破壊的な再構築は行いません
- ホストレベルのリソースはバージョン単位で明示的に移行します
- キャッシュ無効化とより細かな同期は後から追加できます
