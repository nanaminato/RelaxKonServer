# ワークスペース

ワークスペースは、ユーザー設定・アプリの状態・ストレージ・端末情報をサーバーで管理し、複数のクライアントで共有します。

## 含まれるもの

| 内容 | 説明 |
| --- | --- |
| ユーザー設定 | 壁紙、テーマパレット、時刻 / 日付形式、言語、地域、既定プログラム |
| アプリ状態 | ターミナル設定、ブラウザー設定、ブックマークと履歴 |
| ストレージ | ユーザースコープの永続データ |
| デバイス | 接続したことのあるクライアントの記録 |
| ウィンドウレイアウト | デスクトップとウィンドウの配置状態 |

## ワークスペースとデバイス

1 人のユーザーの複数デバイスが**同じワークスペース**に接続します。新しいデバイスでサインインすれば、設定と状態がそのまま現れます。

## Session との違い

ワークスペースは**永続**し、Session は**一時的な接続**です。Session を閉じてもワークスペースは破棄されません。
