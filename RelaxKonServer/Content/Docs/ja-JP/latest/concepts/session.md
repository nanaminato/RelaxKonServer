# セッションとデバイス

## デバイス（Device）

デバイスはワークスペースに接続するクライアントインスタンスです。サーバーはその識別情報と直近の接続を記録し、マルチデバイス運用の提示と管理に利用します。

## セッション（Session）

セッションはデバイスとワークスペースの間の 1 つの接続です。

- サインインで作成され、サインアウトまたはタイムアウトで終了
- 現在のトークンと接続コンテキストを保持
- 同時に複数存在できる（並行デバイス）

## ライフサイクル

```text
デバイス起動
   ↓ サインイン（ホスト OS が検証）
セッション作成
   ↓
ワークスペースへ接続
   ↓
操作 / 同期
   ↓ 切断
セッション終了（ワークスペースは残る）
   ↓ 再接続
新しいセッションが同じワークスペースへ再接続
```

## 永続機能はセッションから独立

ターミナルセッションや監視対象のワークロードは**セッション終了で停止しません**。サーバー上で動作し続け、再接続したクライアントが再アタッチします。
