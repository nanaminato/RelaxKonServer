# セキュリティモデル

RelaxKonOS は独自の ID・権限体系を作らず、**ID とファイル権限をホスト OS に委任**します。

## 3 つの柱

### 1. ID はホストへ委任

- Windows：ネイティブの `LogonUser` API（ローカルアカウントとドメインアカウントに対応）
- Linux：PAM + NSS
- ホストが資格情報を確認した後にのみトークンを発行し、**パスワードを保存しません**

### 2. 権限はホストを継承

- ファイル操作はサインインユーザーのホスト OS 権限で実行
- 独自の ACL 層を持たない
- 権限外の要求はホスト OS が拒否

### 3. 昇格は分離

- 特権操作は専用ヘルパープロセスで実行
- 契約は狭く、監査対象
- 破壊的な操作には明示的な確認が必要
- sudo・UFW・systemd などホストの仕組みを優先的に再利用

## 二層の権限が同時に成立すること

ホスト向けの管理機能（[Docker マネージャー](/docs/ja-JP/latest/apps/docker)、[プロキシーマネージャー](/docs/ja-JP/latest/apps/proxy-manager)、[Web サーバーマネージャー](/docs/ja-JP/latest/apps/web-server-manager)、[証明書マネージャー](/docs/ja-JP/latest/apps/certificate-manager)）は同時に二層の制約を受けます。

```text
RelaxKonOS の認可（ロール / 権限 / 認証済みセッション）
              +
ホスト OS の特権（サービスアカウントの権限、特権ヘルパー）
```

ある構成要素が高い権限で動作していても、**任意の RelaxKonOS ユーザーがそれを制御してよいことにはなりません**。逆に、ユーザーに権限があってもサーバー側にホスト特権があるとは限りません。

## 特権ヘルパーの境界

- サーバーは **root や管理者として動作せず**、ホスト特権を要する操作はすべてヘルパーへ渡されます。
- ヘルパーは**固定の強く型付けされた**操作のみを受け付けます。「root として任意のコマンドを実行」のような汎用入口はなく、任意の実行ファイルや引数も受け付けません。
- 導入時に書き込まれるポリシーファイルがサービスアカウントに許される範囲を決め、ヘルパーのディレクトリとポリシーファイルはそのアカウントから書き込み不可です。
- 日常の起動と停止で**昇格を繰り返すべきではありません**。導入、認可、特権操作の定義は初回に完了し、以後の通常の切り替えに承認は不要です。

## ホスト認可の結果は明示される

- ホスト特権を要する能力は**既定で無効**です。最も分かりやすい例は Docker で、デーモンソケットの制御権は root 権限に近いため、導入時に自動付与せず、明示的に選択する必要があります（[インストール](/docs/ja-JP/latest/getting-started/installation)を参照）。
- 権限が不足すると機能は**安定した問題コード**を返して理由を示し、画面はより高い権限での再導入や再起動を求めます。黙って失敗することはありません。
- ヘルパーが存在しない、削除された、または呼び出しを拒否した場合、該当機能は問題コードで失敗します。**稼働中のワークロードは中断されず**、保存済みの設定もロールバックされないため、原因を修正して再試行できます。
- クライアントは**ローカライズされた説明のみを表示**します。sudo、管理者、サービスアカウントのパスワードを収集せず、API を任意コマンドの昇格経路にしません。

## 多層防御

| レイヤー | 対策 |
| --- | --- |
| 転送 | HTTPS、JWT |
| プロトコル | 明示的な契約、入力検証 |
| サーバー | パス正規化、ディレクトリトラバーサル対策、統一エラー処理 |
| 実行 | シェル連結ではなく構造化引数、破壊的操作の確認、操作監査 |
| 描画 | Markdown のエスケープ、埋め込み HTML を既定で信頼しない |

## 機密とログ

- パスワード、秘密鍵、アカウント鍵、制御シークレット、サブスクリプション URL、プロキシー口令は**ログ、監査、エラー詳細へ入りません**。
- 操作者向けの例外として、プロキシーアドレスのようにフォームを往復する必要がある項目はそのまま返します。そうしないと一度の往復で実資格情報が伏せ字に書き換わります。この場合のマスクは、他の読者に向けたログと診断にのみ適用されます。
- 保存が必要な機密はサーバーのデータ保護機構で暗号化し、API はバージョンまたは参照のみを返します。
