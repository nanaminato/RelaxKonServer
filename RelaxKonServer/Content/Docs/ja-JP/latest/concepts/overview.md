# RelaxKonOS の概要

RelaxKonOS は、個人サーバーや小規模チームサーバーのデスクトップ運用に向けた**クラウドネイティブなデスクトップ OS 環境**です。

## 一言でいうと

UI はデバイスに、ワークスペースはサーバーに。

## 能力マップ

| レイヤー | 構成 |
| --- | --- |
| Client | デスクトップシェル、ウィンドウマネージャー、アプリランタイム、アプリ SDK |
| Protocol | REST 契約、SignalR ハブインターフェース、DTO とシリアル化規約 |
| Server | ID、ワークスペース、ストレージ、同期、リモートランタイム、各種プラットフォームサービス |
| Host | ホスト OS のユーザー、権限、ファイルシステム |

## 中核概念

- **Workspace**：永続的なユーザーコンテキスト
- **Session**：デバイスとワークスペース間の接続
- **Device**：ワークスペースに接続するクライアント
- **アプリケーションモデル**：アプリの宣言・起動・ライフサイクル
- **リモートサービス**：サーバー上で動作する構造化された機能

## 設計原則

1. **ローカル描画** — 操作の遅延をクライアント側に保つ
2. **明示的な契約** — すべての通信はプロトコルを経由する
3. **ホストへの委任** — ID と権限はホスト OS を再利用する
4. **明示的な縮退** — 未対応の能力は正直に示す
