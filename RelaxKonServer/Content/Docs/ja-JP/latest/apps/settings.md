# 設定

設定（Settings）は Windows 11 / GNOME スタイルの設定ハブです。

## カテゴリ

| カテゴリ | 内容 |
| --- | --- |
| システム | システム情報、バージョン情報と更新状態 |
| 個人用設定 | 壁紙、テーマパレット、デスクトップアイコン |
| 時刻と言語 | 時刻 / 日付形式、言語と地域 |
| ネットワーク | アダプターとタイムゾーン（ホスト OS からの読み取り専用）、共有の外向きプロキシー |
| アプリ | 既定のプログラム、アプリ権限 |
| イメージミラー | APT / NPM などのミラーソース。**Docker ミラーは Docker マネージャーへ移動しました** |
| 開発者 | 開発者モード、アプリパッケージ、[ネットワークインスペクター](/docs/ja-JP/latest/apps/network-inspector)の入口 |

## 外向きプロキシー

「ネットワーク」カテゴリーの外向きプロキシーは**サーバー上の一つの共有設定**で、すべての利用者が同じ内容を参照します。明示的にチェックした組み込み機能のみに作用し、**ホスト OS のシステムプロキシーは変更しません**。

- **取得元**：手動入力のアドレス、または内蔵プロキシーランタイムの待ち受けポート。内蔵を選んだ場合、実際に待ち受けているかどうかを画面が示します。
- **HTTPS アドレス**：空欄の場合は HTTP プロキシーのアドレスを再利用します。
- **プロキシーを使わないアドレス**：複数指定する場合は `;` または `,` で区切ります。
- **適用範囲**：機能ごとにチェックします。例として Docker デーモンのイメージ取得、Docker ビルド、イメージタグとバージョンの照会、内蔵ランタイムのダウンロード。
- Docker デーモン層のプロキシーを有効化または削除すると Docker が再起動し実行中のコンテナーが中断されるため、先に確認を求めます。

同じ設定は [Docker マネージャー](/docs/ja-JP/latest/apps/docker)の「ネットワークプロキシー」ページにも現れます。両者は一つの設定を編集するもので、二つ目の真実の源はありません。

## 設定の永続化

ワークスペース設定は `/api/v1.0/workspaces/{id}/preferences` を通じて **Workspace** に保存され、複数デバイスで共有されます。サインイン時に `PreferencesSync` が自動で読み込み、壁紙・タスクバー色・時計形式が即時反映されます。編集は 300 ms のデバウンス後に保存されます。

外向きプロキシーはこの規則の例外で、**サーバー単位**の設定として全利用者が共有し、ワークスペースには追従しません。

### 言語設定

RelaxKonOS Server 接続では、「時刻と言語」で **システムに従う** を選べます。中国語は `zh-CN`、日本語は `ja-JP`、その他のシステム言語は `en-US` に解決され、そのワークスペース設定は他のデバイスにも同期されます。SSH デスクトップは常にクライアントのシステム言語に従い、サーバーのワークスペース設定を読んだり変更したりしません。

## 権限の境界

ホスト OS レベルの設定（タイムゾーン、ネットワークアダプター）は**読み取り専用**で表示されます。RelaxKonOS はホストのシステム構成を変更しません。
