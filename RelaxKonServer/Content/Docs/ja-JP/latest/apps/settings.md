# 設定

設定（Settings）は Windows 11 / GNOME スタイルの設定ハブです。

## カテゴリ

| カテゴリ | 内容 |
| --- | --- |
| システム | システム情報、バージョン情報と更新状態 |
| 個人用設定 | 壁紙、テーマパレット、デスクトップアイコン |
| 時刻と言語 | 時刻 / 日付形式、言語と地域 |
| ネットワーク | アダプターとタイムゾーン（ホスト OS からの読み取り専用） |
| アプリ | 既定のプログラム、アプリ権限 |
| イメージミラー | APT / Docker / NPM などのミラーソース |
| 開発者 | 開発者モードとアプリパッケージ |

## 設定の永続化

設定は `/api/v1.0/workspaces/{id}/preferences` を通じて **Workspace** に保存され、複数デバイスで共有されます。サインイン時に `PreferencesSync` が自動で読み込み、壁紙・タスクバー色・時計形式が即時反映されます。編集は 300 ms のデバウンス後に保存されます。

## 権限の境界

ホスト OS レベルの設定（タイムゾーン、ネットワークアダプター）は**読み取り専用**で表示されます。RelaxKonOS はホストのシステム構成を変更しません。
