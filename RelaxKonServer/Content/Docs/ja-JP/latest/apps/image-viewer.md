# 画像ビューアー

画像ビューアーは、サーバーホスト上にある一般的な画像形式を表示します。

## 機能

- PNG、JPEG などの一般的な形式を開く
- ズームとスクロール
- 複数ウィンドウで複数の画像を表示

## 使い方

スタートメニューから開いて画像のパスを選択するか、ファイルマネージャーの「プログラムから開く」から起動します。

> 画像の描画はクライアントが行い、サーバーはファイルのバイト列を読み取るだけです。
