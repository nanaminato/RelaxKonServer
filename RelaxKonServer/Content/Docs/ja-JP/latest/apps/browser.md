# ブラウザー

内蔵ブラウザー（RemoteBrowser）は**リモートブラウザーではありません**。ページはクライアント自身のネットワークとネイティブエンジンで描画されます。

## 概要

`Avalonia.Controls.WebView` の `NativeWebView` を使用し、Windows は WebView2、macOS は WKWebView、Linux は WebKitGTK を用います。Web 通信はサーバーを経由しません。

## 機能

- ナビゲーション：戻る、進む、更新、停止、ホーム、アドレスバー
- ブックマーク：追加、削除、ダブルクリックで移動、全削除
- 履歴：自動記録、ダブルクリックで移動、1 件削除、全削除
- ブラウザー設定をワークスペースへ同期（ホームページ、リンクの開き先）

## 同期されるもの

| 内容 | 同期 |
| --- | --- |
| ブックマーク、履歴 | する（ユーザーごとに分離） |
| ホームページ、リンクの開き先 | する |
| Cookie、拡張機能の設定 | しない |
| ページ内容 | しない（クライアントのネットワーク） |

## セキュリティ

- ブックマークと履歴は `/api/v1.0/browser/*` でユーザーごとに分離して永続化
- ローカル転送は `127.0.0.1` のみをリッスン
- 未サインイン時はサインインを促します
