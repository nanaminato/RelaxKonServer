# ウェルカム

Welcome は RelaxKonOS の起動時に開き、使い方の案内とシステムの確認を行います。

## 機能

- クライアントとサーバーの接続状態を表示
- アプリケーションランタイムとウィンドウマネージャーの動作を確認
- ドキュメント、設定、サンプルアプリへの入口を提供

## 使い方

サインイン後に自動で開きます。閉じてもスタートメニューから再度開けます。
