# ネットワークインスペクター

ネットワークインスペクター（Network Inspector）は、RelaxKonOS シェルが直接所有する**システムデバッグウィンドウ**です。ごく低い常駐コストで、**RelaxKonOS クライアントから RelaxKonOS サーバー**への呼び出しを確認します。開発者ツールのネットワークパネルを参考にしていますが、汎用のパケットキャプチャーを目指すものではありません。

**組み込みアプリではなく**、インストールも不要で、アプリ一覧にも現れず、外部アプリへこの能力を公開しません。

## 概要

採用している信頼境界は「システムウィンドウ、ホスト収集」です。コレクターはクライアントホスト内のシングルトンで、メモリ上限、サニタイズ、分類、イベント購読を担います。インスペクターウィンドウは、すでにサニタイズされたイベントストリームを読むだけです。

記録は**既定では行いません**。開発モードが有効で、利用者が記録を開始したときだけ収集します。記録の停止、開発モードの終了、サインアウトのいずれでもメモリ内の記録は即座に消去されます。

## 開き方

| 入口 | 動作 |
| --- | --- |
| 設定 → 開発者 → ネットワークインスペクター | 状態と開く操作を表示します。開発モードが無効なときは理由を示して操作を無効化します |
| `Ctrl+Shift+I` | メインウィンドウのトンネルルーティングで処理し、どの子ウィンドウにフォーカスがあるかに依存しません |

## 対象範囲

| 項目 | 対象 |
| --- | --- |
| RelaxKonOS の REST 呼び出し（サインイン、設定、ファイル、ブラウザーデータ、タスク管理、ケイパビリティトークンなど） | 含む |
| ターミナルハブの接続、ネゴシエーション、呼び出し結果、接続状態 | 含む |
| ダウンロード、アップロード、メディア再生 | 要約のみで本文は保持しません |
| 要求と応答の本文 | 任意の小型プレビューのみ。厳密にサニタイズし切り詰めます |
| Web ビュー内のサイト通信、サードパーティー構成要素の任意の外向き通信、サーバー側の内部要求 | 含まない |
| ハブのメッセージフレーム、ターミナルの入出力、下位ソケットのペイロード | 含まない |

「すべての呼び出し」とは、この制御された通信境界に入る RelaxKonOS API 呼び出しを指し、端末全体のネットワーク通信ではありません。

## 現在の機能

- 絞り込み：テキスト、ステータスコード、種別、発生元。
- 詳細：概要、要求、応答、タイムラインの四つのタブ。メディアの記録は結果の要約と安全なヘッダーのみを表示します。
- 保持：リングバッファーは固定の件数と推定ペイロードで、どちらかの上限に先に達した方から最古の項目を破棄します。ディスクへ書かず、送信もしません。
- 色は補助にすぎず、テキストの状態も併記するため、テーマとアクセシビリティが機能します。

## 権限とセキュリティ

記録の開始には、開発モードが有効、呼び出しパッケージが導入済み、ローカル利用者が承認した権限がある、認証済みセッション中である、のすべてが必要です。前提が一つでも崩れると収集は停止・消去し購読者へ通知するため、すでに開いている外部ウィンドウが権限取り消し後に古い機密記録を読み続けることはできません。

- 認証ヘッダー、Cookie、機密名を含むヘッダーとフィールド、URL 内の同名クエリーパラメーターは、すべて伏せ字のプレースホルダーに置き換えます。
- メディア、バイナリ、ストリーミングの応答は**決して読み取りもバッファリングもしません**。記録するのはメソッド、サニタイズ済みパス、成功／失敗、ステータスコード、所要時間、コンテンツタイプのみです。
- キャンセルとネットワーク障害も一つのイベントとして記録し、例外の種別と長さを制限した安全な説明のみを残し、例外テキストをそのまま保存しません。

## プラットフォーム差

ありません。挙動はクライアントホストのみに依存します。

## 既知の制限

- Web ビュー内の通信、サードパーティー構成要素が独自に作成した通信、ホスト上の他プロセスの通信は取得しません。
- ハブのメッセージフレームとターミナルのバイトは記録しません。したがって「接続が確立したか、呼び出しが失敗したか」には答えられますが、ターミナルセッションの内容を復元することはできません。
- 要求の再生、編集、遮断は提供せず、キャプチャーファイルの書き出しも行いません。
- ターミナル接続は現在自動再接続を有効にしていないため、切断後はターミナルを開き直す必要がある旨のみを示し、再接続のタイムラインは表示しません。
