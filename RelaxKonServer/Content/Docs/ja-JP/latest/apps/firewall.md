# ファイアウォール

ファイアウォールアプリは **Linux サーバーホスト**の **UFW** を管理します。

## 機能

- 有効 / 無効の状態を読み取り
- 番号付きルール一覧
- 有効状態と既定ポリシーの変更
- 構造的に検証されたルールの追加と削除

## 使い方

開いて現在の状態を確認します。状態、ポリシー、ルールを変更するときは、非 root ユーザーは**自身のパスワード**で PAM による 1 回の確認が必要です。

## 権限とセキュリティ

- Linux 専用。Windows Server では表示されません
- root セッションは再認証を求められません
- 他のユーザーは変更ごとに PAM で 1 回確認します
- ルールは構造的に検証され、任意のコマンド注入はできません
