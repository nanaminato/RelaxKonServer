# ファイアウォール

ファイアウォールアプリは Linux の UFW と、Windows 10/11・Windows Server の Windows Defender Firewall に対応します。Windows システムモードと Windows 10/11 個人モードでは特権 Helper を使用します。

## 機能

- 有効 / 無効の状態を読み取り
- 番号付きルール一覧
- 有効状態と既定ポリシーの変更
- 構造的に検証されたルールの追加と削除

## 使い方

開いて現在の状態を確認します。状態、ポリシー、ルールを変更するときは、共通のホスト管理者認証を使用します。検証済み管理者は再認証不要で、他のユーザーは権限昇格画面で管理者を認証します。

## 権限とセキュリティ

- Linux は UFW、Windows はネイティブファイアウォール API を使用します
- root セッションは再認証を求められません
- 他のセッションは共通の一時ホスト管理者権限を使用します
- ルールは構造的に検証され、任意のコマンド注入はできません

## Windows ファイアウォール

- 状態の確認、有効化・無効化、既定の受信・送信ポリシー変更に対応します。
- 有効状態と既定ポリシーの変更は**ドメイン・プライベート・パブリック**の全プロファイルに適用されます。既定値が異なる場合、統一された値は表示されません。
- 本アプリの管理ルールを追加・編集・削除できます。システム、他のアプリ、グループポリシー、インストール Helper のルールは一覧に含まれません。
- 許可／ブロック、受信／送信、TCP／UDP／任意、IP/CIDR、ポート範囲に対応します。任意プロトコルには任意ポートが必要です。ポートは受信時のローカルポート、送信時のリモートポートです。
- UFW の reject と limit は利用できません。ルールは全プロファイルに適用されるため、必要な送信元・宛先範囲を指定してください。
- 変更は共通のホスト管理者認証と Helper の Windows ネイティブ操作を使用します。Helper の利用不可やポリシー制限はエラーになります。

変更により管理接続が切断される場合があります。他の Windows ルールは管理者が `wf.msc` で管理できます。個人モードのインストール画面が作成する LAN ルールは Domain/Private と LocalSubnet に限定され、別に管理されます。
