# ファイルマネージャー

ファイルマネージャー（Explorer）は、**サーバーホスト**のファイルをローカルのように操作できますが、リモートデスクトップ型のファイル閲覧ではありません。

## 概要

UI は Jaya File Manager から移植されています。すべてのファイル操作はサーバー REST API（`/api/v1.0/files/*`）経由で実行され、サーバーはホスト OS プロセスとしてファイルシステムを操作するため、**ホストのユーザーと権限をそのまま利用**し、別の ACL を持ち込みません。

## 機能

- ナビゲーションツリー（遅延読み込み）、グリッド表示、アドレスバー、ツールバー、ステータスバー
- 閲覧、フォルダー作成、削除、名前変更、コピー、移動
- アップロードとダウンロード
- ファイル / フォルダーのプロパティ表示（Linux では POSIX 権限を編集可能）
- アプリマニフェストの拡張子宣言による「既定で開く」「アプリで開く」

## 権限とセキュリティ

- すべての操作は**サインインユーザー**のホスト OS 権限で実行されます
- 権限外のアクセスはホスト OS が拒否し、RelaxKonOS はそれを迂回しません
- 独自の昇格経路はなく、特権は常にホストへ委任されます
