# ファイルマネージャー

> このページは現在のソース機能を説明し、特定パッケージの収録機能一覧ではありません。公開成果物と日付は[リリースノート](/releases/0.1.2)、検証状況はリンク先の実装記録で確認してください。

ファイルマネージャー（Explorer）は、**サーバーホスト**のファイルをローカルのように操作できますが、リモートデスクトップ型のファイル閲覧ではありません。

## 操作例：ディレクトリとファイル転送

1. Server ワークスペースはホストのファイル、SSH デスクトップは SFTP を使います。ホストとアカウントを確認し、スタートからファイル管理を開きます。
2. ナビゲーションやアドレス欄で許可された対象へ進み、パスと一覧を確認します。システムディレクトリではなくテスト用で始めます。
3. テストフォルダーを作って入り、同名ファイルと競合処理を確認します。
4. 小さなローカルファイルをアップロードし、転送と確定後に一覧を更新して名前・サイズを確認します。100% だけでは確定完了ではありません。
5. ダウンロードして本機で内容を確認します。名前変更・コピー・移動の前に選択項目と移動先を照合します。

閲覧拒否は空ディレクトリとせず、ユーザーとパス認可を確認します。Linux ユーザーは現在の Unix home、Windows 個人ヘルパーは確認済み範囲に従います。削除前に項目を照合し、ごみ箱や復元を前提にしません。大容量の中断は[転送手順](/docs/ja-JP/latest/apps/file-transfers)を参照してください。

## 概要

UI は Jaya File Manager から移植されています。RelaxKonOS Server のワークスペースでは、すべてのファイル操作がサーバー REST API（`/api/v1.0/files/*`）を通じて実行され、サインインしたホストユーザーの権限を再利用します。別の ACL は作りません。SSH デスクトップでは専用の SFTP ファイルブラウザーを使用します。これは確認済みの SSH 接続に限定され、RelaxKonOS Server API は呼び出しません。

## 機能

- ナビゲーションツリー（遅延読み込み）、グリッド表示、アドレスバー、ツールバー、ステータスバー
- 閲覧、フォルダー作成、削除、名前変更、コピー、移動
- アップロードとダウンロード
- ファイル / フォルダーのプロパティ表示（Linux では POSIX 権限を編集可能）
- アプリマニフェストの拡張子宣言による「既定で開く」「アプリで開く」
- テーマに追従するベクターアイコン。ライト / ダークの外観に合わせて切り替わり、高解像度ディスプレイでも鮮明です

## 使い方

スタートメニューからファイルマネージャーを開き、フォルダーをダブルクリックして移動し、ファイルをダブルクリックすると宣言された方法で開きます。削除などの危険な操作では確認ダイアログが表示されます。

## 権限とセキュリティ

ファイル操作はホスト ID とパス権限に従い、閲覧拒否は空ではなくアクセス不可と表示します。システムモードの保護ディレクトリは限定されたファイル認可と固定 Helper を使用し、期限切れは再確認します。ユーザーモードは現在の Unix home に限定し昇格できません。アクセス問題のために Server を root/管理者として実行しないでください。

システムモードでは保護フォルダーの読み取り認可は 5 分間有効で、現在のログイントークンに結び付きます。そのフォルダーと配下のファイル・サブフォルダーを対象とし、期間内は配下の閲覧や画像表示で管理者資格情報を再入力する必要はありません。単一ファイルの認可はそのファイルだけが対象です。他のフォルダーは対象外で、書き込みと削除は別途認可が必要です。ログアウト時に認可を取り消します。
