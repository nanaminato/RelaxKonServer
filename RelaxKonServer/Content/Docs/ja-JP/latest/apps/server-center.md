# サーバーセンター

> 現在のソース機能を説明します。公開パッケージの内容は[リリースノート](/releases/0.1.2)、検証状況は関連する実装文書を参照してください。

サーバーセンターは、RelaxKonOS Server または直接 SSH を使ってリモートホストへの接続と導入を管理します。

## Windows 10/11 の個人用 PC

Windows 10/11 デスクトップのログイン画面には SSH や既存の Server ログインが不要な**本機を管理**があります。個人モードが既定で、システムモードも選べます。導入・更新・修復・ロールバック・削除は対象の識別子を確認し、特権ヘルパーの設定で UAC を使います。状態の更新は UAC 不要です。別の管理者が UAC を承認しても所有者は開始ユーザーのままです。本機管理と端末認証は[Windows 10/11 の個人用 PC](/docs/ja-JP/latest/getting-started/windows)を参照してください。

## 接続方法を選ぶ

| 接続 | 利用できるもの | 利用できないもの |
| --- | --- | --- |
| RelaxKonOS Server | サインイン、永続ワークスペース、設定同期、アカウントに公開されたサーバー機能 | 任意のホストを管理する SSH の代替 |
| SSH | 確認済み SSH ホスト向けの専用デスクトップ。ターミナル、サーバーセンター、SSH ファイルブラウザー、コードエディタ、画像ビューア | RelaxKonOS ワークスペース、Docker・ファイアウォール・証明書マネージャーなどサーバー専用アプリ |

SSH はサーバー導入前のホスト接続や既存ホストの保守に使えます。SSH エンドポイントを管理対象の RelaxKonOS Server に変換するものではありません。

## SSH の信頼と保存済み接続

初回接続前に、クライアントはホスト鍵のフィンガープリントを表示します。**信頼して接続** を明示的に選んだ場合だけ保存され、キャンセルまたはダイアログを閉じても信頼記録は変わりません。保存済み接続にはホスト、ポート、ユーザーが記録されます。保存するパスワードは OS の安全な資格情報ストアで扱われ、RelaxKonOS ワークスペースには保存されません。

SSH デスクトップはクライアントのシステム言語に従います。RelaxKonOS ワークスペースの言語設定を読んだり上書きしたりしません。

## サーバーの導入と保守

確認済み SSH ホストに対して、サーバーセンターは事前チェック、ホスト状態の確認、次の操作を案内します。

- 検証済みリリースパッケージによる初回導入またはアップグレード
- 修復、ロールバック、アンインストール
- ランチャーの終了コードを成功とみなすのではなく、ホスト側の最終操作結果を確認

Linux システムモードは root または認証済み sudo、ユーザーモードは sudo 不要の通常アカウントを使用します。Windows システムモードは昇格済み管理者の SSH セッションが必要です。入手元、ポート、ディレクトリ、ネットワーク、TLS、ファイル範囲、Linux の権限範囲、Docker は[インストールガイド](/docs/ja-JP/latest/getting-started/installation)を参照してください。

アンインストールは既定でサーバーデータを残します。データ削除は明示的な破壊的操作であり、サーバー名の再確認が必要です。

## セキュリティ境界

- 事前チェックの結果を表示し、明示的な確認を受けてからデプロイします。
- SSH ホスト鍵の検証により、異なるホストを黙って受け入れることを防ぎます。
- サーバーセンターは SSH 接続を権限昇格の経路にはしません。ホスト状態を変更する機能には、引き続きサーバーの認可モデルが適用されます。
