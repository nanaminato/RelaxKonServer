# コードエディター

コードエディターは**サーバーホスト上**のコードファイルを、シンタックスハイライトとマルチエンコーディング対応で編集します。

## 機能

- シンタックスハイライトと慣れ親しんだ編集操作
- 複数エンコーディングでの読み書き（UTF-8、GBK、Shift-JIS など）
- メモ帳と共通のエンコーディングダイアログ
- 複数ウィンドウで複数ファイルを同時に編集

## 使い方

スタートメニューから開くか、ファイルマネージャーの「プログラムから開く」で拡張子に関連付けて起動します。保存すると**サーバー上**のファイルへ書き戻されます。

## 権限とセキュリティ

- 読み書きはサインイン中のユーザーのホスト OS 権限で実行されます
- その範囲外のパスはホスト OS によって拒否されます
- エディターが独自のファイルアクセス経路を追加することはありません
