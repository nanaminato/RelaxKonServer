# メモ帳

メモ帳はプレーンテキスト向けの軽量エディターで、主に**クロスプラットフォームの文字コード**の問題を解決するために作られました。

## 機能

- リモートのテキストファイルを開いて保存
- 複数のエンコーディング：UTF-8、GBK、Shift-JIS など
- コードエディターと共通のエンコーディングダイアログ
- 複数ウィンドウ

## 使い方

スタートメニューからメモ帳を開き、「開く」でサーバー上のパスを選択します。判定されたエンコーディングが正しくない場合は、エンコーディングダイアログで正しいものを選んで再読み込みします。
