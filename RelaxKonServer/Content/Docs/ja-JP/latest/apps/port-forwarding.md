# ポートフォワーディング

ポートフォワーディングは、サーバー側のサービスを手元の `127.0.0.1` にマッピングするローカル SSH フォワードを作成します。

## 機能

- 要求されたポートが空いていればそれをバインドし、そうでなければ利用可能なループバックポートを選びます
- 実際に使用できるローカルリンクを返します
- 実行中のトンネルの一覧表示、更新、停止
- ブラウザーや他のファーストパーティサービスからも要求できます

## 使い方

1. ポートフォワーディングを開く
2. 対象ホストとリモートポートを選択する
3. 生成された `http://127.0.0.1:<port>` リンクをコピーする
4. ブラウザーで開く

## ワークスペースとの関係

SSH 設定と実行中のトンネルは**クライアント側にのみ**保存され、ワークスペースへは同期されません。これは意図的な設計です。トンネルは「この端末からサーバーへのネットワーク経路」を表すものだからです。

## セキュリティ

- トンネルは `127.0.0.1` にのみバインドされ、LAN へ公開されることはありません
- ホストの SSH 資格情報を使用し、RelaxKonOS が追加の鍵を保存することはありません
