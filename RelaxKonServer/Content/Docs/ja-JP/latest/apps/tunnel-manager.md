# トンネルマネージャー

トンネルマネージャー（Tunnel Manager、「内網穿透」）は、プロトコル実装をメインプロセスへ結合せずにローカルサービスを遠隔へ公開します。

中心となる取捨は次のとおりです。**RelaxKonOS がトンネルをネイティブに管理しつつ、`frpc` / `frps` は常に独立したプロセスとして動作します。** 実際のトラフィックは FRP プロセス間でのみ転送され、RelaxKonOS はデータ転送に関与せず、トンネルの生存に自身の可用性を依存させません。

## 概要

- **データベースが真実の源で、生成された設定はそうではありません。** トンネルとサーバープロファイルは検証・監査可能な希望状態として保存し、生成された設定ファイルは成果物にすぎません。
- **プロバイダーを中心にモデル化**し、FRP は最初の実装です。将来別のトンネル方式を追加しても呼び出し側は変わりません。
- RelaxKonOS のサーバー、認証、LAN アクセス、修復経路は**トンネルの生存に依存しません**。

## 利用が適する場面

- 公衆からの入口がないマシンで、一つ以上のポートを公開したい。
- RelaxKonOS が管理するサーバー、自前のサーバー、またはサードパーティー互換のサーバーへ接続したい。
- RelaxKonOS 管理のランタイムと、OS に既にある FRP の両方を使いたい。

## 現在の機能

- トンネル定義を希望状態として保存し、適用前に検証します。
- サーバープロファイル：ホスト、ポート、認証、トランスポートなど秘密でない部分。秘密材料はサーバー内部でのみ参照します。
- ランタイム管理：ダウンロード、検証、バージョン付き導入、起動、停止、状態、ログ、更新、ロールバック。更新はバージョンディレクトリのポインター切り替えで、既存バイナリを上書きしません。
- 外部ランタイム：検出と明示的な管理対象起動のみで、**認可されていない設定やプロセスを決して引き継ぎません**。
- トンネル種別：初版は `tcp`、`udp`、`http`、`https` に対応します。
- 管理対象サーバー：RelaxKonOS がホストするサーバーを扱い、設定と診断のページを提供します。
- 画面：概要、トンネル、サーバー、ランタイムとログ、セキュリティ状態。

## 権限とセキュリティ

- 秘密情報は通常の API、ログ、生成設定のダウンロード口、クライアント経由のいずれからも漏れません。
- ランタイムの実行ファイルパスとコマンドラインはサーバーの定数と構造化引数で決まり、**シェル文字列へ連結しません**。
- OS がランタイムのバイナリを遮断・隔離した場合、RelaxKonOS は診断情報を表示するのみです。**アンチウイルスの無効化、全体除外の追加、パッキング、バイナリの改変によってセキュリティソフトを迂回することはありません**。
- 変更操作には対応する読み取りと管理の権限が必要で、監査されます。

## プラットフォーム差

Windows、Windows Server、Linux に対応します。差異は主にランタイムのプロセス監督方法と OS のセキュリティソフトの挙動で、いずれもサーバー側にカプセル化されます。

## 既知の制限

- 本バージョンは `STCP`、`XTCP`、P2P visitor、プラグイン、独自の設定断片、任意の環境変数、任意のコマンドライン引数の透過を**含みません**。これらには独立した秘密・ネットワーク露出・入力モデルが必要です。
- **RelaxKonOS 自身を自動的に公衆網へ公開しません。** この能力は別個のリモートアクセス / TLS / アイデンティティ審査に属し、明示的で取り消し可能なシステムトンネルとして実装すべきものです。
- **サーバー側バイナリの自動導入や強制有効化は行いません**。サーバーは後続の任意目標で、クライアント側の主経路を妨げません。
- Cloudflare Tunnel、Tailscale などは抽象の境界のみで、実装していません。
- トンネルプロトコルの埋め込みや書き換えは行わず、RelaxKonOS はデータ転送に関与しません。
