# ユーザーモードでのインストール（Linux）

Linux ユーザーモードは通常のアカウントでサーバーを実行し、sudo、システムサービス、特権ヘルパーを使用しません。`127.0.0.1` のみを使用し、リモート接続にはクライアントが管理する SSH トンネルを使用します。

## サーバーセンターからインストール

1. [ダウンロード](/downloads)からクライアントを取得し、サーバーセンターで Linux ホストに接続してホスト鍵を確認します。
2. 非 root アカウントで事前チェックを実行し、ウィザードで **Linux ユーザーモード**を選択します。
3. 公式安定版、ローカル ZIP、サーバー上の ZIP、カスタム HTTPS ダウンロードから選びます。`*-user-server.zip` が必要で、システム用パッケージは代用できません。
4. ポート（既定は 5000）を指定し、必要に応じてデータ、設定、状態、キャッシュのディレクトリを設定します。空欄では下記の XDG 既定値を使用します。
5. 設定を確認して実行し、`/ready` の正常性チェックと最終結果を待ち、クライアントの SSH トンネルでログインします。

公開状況はダウンロード一覧に従います。未公開の場合は適切なユーザーモードパッケージを準備してください。ホストには Bash、Python 3、curl、unzip、realpath、stat、find、sha256sum、flock が必要で、systemd は不要です。

## ディレクトリと権限

| 用途 | 既定のパス |
| --- | --- |
| プログラムとバージョン | `${XDG_DATA_HOME:-$HOME/.local/share}/relaxkonos/` |
| 設定と鍵 | `${XDG_CONFIG_HOME:-$HOME/.config}/relaxkonos/` |
| 状態、データベース、ログ | `${XDG_STATE_HOME:-$HOME/.local/state}/relaxkonos/` |
| キャッシュ | `${XDG_CACHE_HOME:-$HOME/.cache}/relaxkonos/` |

重ならない絶対ディレクトリを使用します。プライベートなディレクトリとファイルの権限は `0700` / `0600` です。ホスト側にディレクトリの情報を保存し、再接続後も実際のインストール場所を管理します。

PAM、sudoers、システムのファイアウォールは変更せず、Docker 管理などの特権機能は無効です。ネットワークはローカル限定で、システムモードの TLS と特権ファイル範囲は使用しません。

## 更新とアンインストール

サーバーセンターでホストを選び、更新、修復、ロールバック、アンインストールを実行します。外部 SSH クライアントやライフサイクルコマンドの手入力は不要です。準備完了の確認に失敗すると復旧を実行し、最終結果で確認します。既定ではデータを保持し、完全削除には別途確認が必要です。

ポート競合、依存関係不足、パッケージ種類やアーキテクチャの不一致、摘要の検証失敗、操作ロックは処理を停止します。事前チェックと操作履歴を確認してから再試行してください。

全設定は[インストール](/docs/ja-JP/latest/getting-started/installation)、入口は[サーバーセンター](/docs/ja-JP/latest/apps/server-center)を参照してください。
