# クイックスタート

サインインすると RelaxKonOS のデスクトップが表示されます。まずはよく使う操作から。

## デスクトップとウィンドウ

- **スタートメニュー**：左下のボタンでアプリ一覧を表示
- **ウィンドウの移動**：タイトルバーをドラッグ、8 方向リサイズ対応
- **最小化 / 最大化 / 閉じる**：タイトルバー右側のボタン
- **全画面と接続バー**：全画面時は接続バーが表示され、固定または自動非表示にできます

## アプリを開く

スタートメニューから任意のアプリをクリックします。多くはシングルウィンドウ（設定、タスクマネージャー、Docker、ファイアウォールなど）で、Notepad とコードエディタはマルチウィンドウに対応します。

## 試してみる

1. **ターミナル**を開き `uname -a` や `ver` を実行 — 出力はローカルで描画されます
2. **ファイルマネージャー**でホストのファイルシステムを閲覧
3. **タスクマネージャー**でリアルタイムの性能グラフを確認
4. ネットワークを切断してから再接続 — ターミナルセッションは残っています

> 手順 4 が要点です。セッションはサーバー上にあり、クライアントはその表示にすぎません。
