# ファイル管理とターミナルの最初の操作

デスクトップクライアントと RelaxKonOS Server ワークスペースを例に説明します。利用できる機能はクライアントとサーバーのバージョン、インストールモード、アカウント権限によって異なります。

## 1. サーバーのフォルダーを開く

ファイルマネージャーで自分のユーザーディレクトリを開きます。フォルダーをダブルクリックし、アドレスバーで場所を確認します。ユーザーモードは現在の Unix home に制限されます。アクセス拒否時はアカウントとパスを確認してください。

![スクリーンショット：サーバーのフォルダーを開く](/assets/tutorials/ja-JP/tutorial-files-terminal-1.svg)

*スクリーンショット：サーバーのフォルダーを開く*

## 2. 練習用フォルダーを作る

書き込み可能な場所に relaxkon-tutorial などのフォルダーを作り、名前変更を試します。自分の練習用ファイルを使い、削除時は対象を確認してください。アップロードとダウンロードは[ファイル転送](/docs/ja-JP/latest/apps/file-transfers)を参照してください。

![スクリーンショット：練習用フォルダーを作る](/assets/tutorials/ja-JP/tutorial-files-terminal-2.svg)

*スクリーンショット：練習用フォルダーを作る*

## 3. ターミナルの接続先を確認する

スタートからターミナルを開きます。Linux shell では pwd、whoami、uname -a を順に実行します。Windows コマンドプロンプトでは cd、whoami、ver を使います。読み取り専用コマンドでサーバー、アカウント、現在の場所を確認できます。

![スクリーンショット：ターミナルの接続先を確認する](/assets/tutorials/ja-JP/tutorial-files-terminal-3.svg)

*スクリーンショット：ターミナルの接続先を確認する*

## 4. ファイルとセッションを理解する

両アプリはサーバー上のリソースを操作します。ターミナルの作業ディレクトリはファイルマネージャーに自動追従しません。Server のターミナルは短時間の切断でもセッションを維持できますが、サーバー再起動や明示的な終了は別途確認が必要です。タスクが永久に動くとは限りません。[ターミナル](/docs/ja-JP/latest/apps/terminal)を参照してください。
