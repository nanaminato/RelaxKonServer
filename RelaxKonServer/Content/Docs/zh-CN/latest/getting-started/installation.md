# 安装

RelaxKonOS 由客户端与服务端组成。先在自己的设备上安装客户端，再通过**服务器中心**安装或维护服务端。

## Windows 10/11 本机安装

在自己的 Windows 10/11 电脑上，从桌面客户端登录页选择**管理本机**。默认个人模式，也可选系统模式，无需启用 SSH。个人模式由当前用户拥有，安装和维护通过 UAC 配置特权助手；Server 登录后启动、注销后停止。安装后用回环地址完成本机授权，再用授权码配对其他设备。完整步骤、模式区别与权限范围见[Windows 10/11 个人电脑](/docs/zh-CN/latest/getting-started/windows)。Windows Server 仅支持系统模式。

## 安装前准备

- 从[下载页](/downloads)取得适合自己设备的客户端；使用发布包不需要 .NET SDK。Android 的安装说明见[Android 客户端](/docs/zh-CN/latest/getting-started/android)。
- 远程安装需要目标主机启用 SSH，并准备管理账号；连接时核对主机密钥指纹。Windows 10/11 本机管理不需要 SSH。
- Linux 系统模式默认支持 Debian 12、Ubuntu 22.04/24.04/26.04，需要 root 或可用的 sudo、systemd 和 Python 3；其他 Linux 系统需要在高级选项中明确允许。
- Linux 用户模式使用普通账号，禁止 root；需要 Bash、Python 3、curl、unzip、realpath、stat、find、sha256sum 与 flock，不需要 sudo 或 systemd。
- Windows 10/11 支持个人模式与系统模式；Windows Server 仅支持系统模式。Windows 系统模式的远程安装需要已提升的管理员 SSH 会话，本机安装通过管理员权限完成；均需系统 PowerShell。
- 安装前检查架构、可用空间、依赖和端口。远程首次安装前通过 SSH；Windows 本机管理直接调用本机部署引擎。

## 在客户端远程安装（SSH）

1. 打开客户端的**服务器中心／安装或管理服务器**。桌面端也可以从登录窗口选择 SSH，连接后打开服务器中心。
2. 添加主机，填写 SSH 地址、端口和账号，核对并确认主机密钥。
3. 执行环境检查，选择**安装服务端**。已安装主机会执行升级，并核对已有安装标识。
4. 选择安装来源与模式，填写安装选项，再审阅目标主机和配置。
5. 确认安装，等待服务器侧操作结果记录和健康检查。安装失败时查看操作记录中的原因与日志。
6. 安装成功后返回登录入口；用户模式及仅本机监听可通过客户端管理的 SSH 隧道连接。

## 安装来源

| 来源 | 操作与检查 |
| --- | --- |
| 官方稳定版 | 由目标主机下载发布包，自动检查官网 ZIP 摘要和逐文件清单；可设置 HTTPS 发布目录地址 |
| 本地发布包 | 在客户端选择 ZIP 并上传；适合目标主机离线的情况 |
| 服务器上的发布包 | 浏览或填写服务器 ZIP 的绝对路径，直接读取服务器文件 |
| 自定义 HTTPS 下载 | 填写发布 ZIP 的 HTTPS 地址和完整的 64 位十六进制 SHA-256，下载后核对摘要 |

本地与服务器文件仍检查包类型、架构、必要文件和安全解压布局。系统模式使用 `*-server.zip`，用户模式使用 `*-user-server.zip`，客户端包不能代替服务端包。实际可下载的版本以下载目录为准。

## 安装选项

| 选项 | 适用范围与说明 |
| --- | --- |
| 安装模式 | Linux 系统／用户模式，Windows 系统模式；Windows 10/11 本机管理另支持个人模式且默认选择它。远程自动模式按主机预检推荐 |
| 服务端端口 | 1–65535，默认 5000；应选择可用端口 |
| 程序与数据目录 | 系统模式可分别设置程序和数据目录；用户模式的数据目录同时保存程序。留空采用默认值，已有安装沿用记录的目录 |
| 配置、状态与缓存目录 | Linux 用户模式可分别设置四个 XDG 对应目录；使用绝对路径，避免目录重叠 |
| 网络访问 | 系统模式选择仅本机或局域网；用户模式向导默认仅本机，可通过 `listen-host` 配置启用 LAN。局域网监听不会自动开放防火墙 |
| TLS 证书 | 系统模式选择无证书、自有证书或自签名证书；自有证书填写密码并选择 PFX/P12，或 PEM 证书链与私钥；自签名填写逗号分隔的名称 |
| 文件访问范围 | 系统模式选择受限、白名单或全部文件；白名单每行填写一个服务器上的绝对目录 |
| 管理员与 root 文件范围 | Linux 系统模式分别设置访问范围及白名单，与普通身份的范围独立 |
| Docker 授权 | Linux 系统模式需显式勾选授权；默认关闭。Docker 套接字的控制权接近 root 权限 |
| 非标准 Linux 系统 | 明确勾选允许支持列表之外的系统；不会跳过架构、权限或依赖检查 |
| sudo 凭据 | Linux 系统模式使用 root，或提供 sudo 密码；留空时尝试当前 SSH 密码 |

安装向导自动处理界面语言、固定部署动作、非交互执行、包暂存路径、证书密码暂存文件和已有安装标识。无需手动填写脚本参数。证书密码不会显示在审阅页。

Windows 10/11 个人模式使用固定的用户程序、数据与部署记录目录。网络、TLS 和特权文件范围在安装审阅页配置；LAN 监听不会自动开放防火墙，可显式选择仅允许 Domain/Private 网络 LocalSubnet 的个人防火墙规则。

## 更新、修复与卸载

在服务器中心选中已安装主机，再进入维护操作。升级、修复与回滚继续使用安装记录的目录；保留数据的重新安装会沿用安装身份。普通升级或修复保留现有 TLS 身份，重新生成证书需明确选择。

卸载默认保留数据。永久删除数据库、配置、密钥与日志需要单独确认；完成后客户端再次核验服务器安装状态。权限助手不可用时，可查看操作记录并执行修复。

## 首次登录

Windows 10/11 个人模式在健康检查后先完成本机设备授权，随后使用设备密钥登录；系统账号与 Alias 的流程适用于支持它们的模式。详见[Windows 10/11 个人电脑](/docs/zh-CN/latest/getting-started/windows)。

安装健康检查通过后，使用服务器操作系统账号或已配置的 Alias 登录。系统账号由服务器操作系统验证；Alias 使用独立密码哈希。服务端不持久保存系统登录密码，记住凭据是本机安全存储的显式选择。
