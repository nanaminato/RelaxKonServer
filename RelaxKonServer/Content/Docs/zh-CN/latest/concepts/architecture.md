# 客户端 / 服务端架构

RelaxKonOS 使用**状态同步**模型，而不是像素流模型。

## 职责划分

### 客户端

- 桌面 Shell、任务栏、开始菜单
- 窗口管理器与模态对话框
- 应用 UI 与本地渲染
- 输入处理与键盘路由

### 服务端

- 身份与登录
- 工作区生命周期与设备
- 存储与同步
- 远程运行时与远程服务
- 平台服务（Docker、防火墙、证书、Web Server、Git、隧道、代理等）

> 服务端**从不捕获或生成桌面图像**。

## 一次典型交互

```text
1. 用户在客户端窗口输入
2. 客户端把「意图」编码为协议消息
3. 服务端在宿主 OS 上执行操作
4. 服务端返回结构化结果
5. 客户端以原生控件渲染结果
```

## 为什么不是像素流

| 维度 | 像素流 | 状态同步 |
| --- | --- | --- |
| 传输内容 | 图像帧 | 状态与意图 |
| 文本清晰度 | 受分辨率限制 | 原生渲染，始终清晰 |
| 交互延迟 | 包含编码与传输 | 本地处理 |
| 带宽 | 与画面变化相关 | 与操作量相关 |
