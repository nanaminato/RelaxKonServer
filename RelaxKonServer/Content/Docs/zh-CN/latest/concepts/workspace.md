# 工作区

工作区（Workspace）是服务端管理的持久上下文，承载用户偏好、应用状态、存储与设备信息，让体验不依赖某一台客户端设备。

## 包含什么

| 内容 | 说明 |
| --- | --- |
| 用户偏好 | 壁纸、主题调色板、时间 / 日期格式、语言、区域、默认程序 |
| 应用状态 | 终端设置、浏览器设置、书签与历史 |
| 存储 | 用户级持久数据 |
| 设备 | 曾连接过的客户端设备记录 |
| 窗口布局 | 桌面与窗口排布状态 |

## 工作区与设备

同一位用户的多个设备连接到**同一个工作区**。换一台设备登录后，偏好与状态会随之出现，无需重新配置。

```text
             ┌──────────────┐
  Device A ──┤              │
             │  Workspace   │
  Device B ──┤  (persistent)│
             │              │
  Device C ──┴──────────────┘
```

## 与 Session 的区别

工作区**持久存在**，Session 是**临时的连接**。断开 Session 不会销毁工作区。
