# 图片查看器

图片查看器用于快速查看服务端宿主系统上的常见图片格式。

## 功能

- 打开 PNG / JPEG 等常见格式
- 缩放与滚动
- 多窗口查看多张图片

## 使用方式

从开始菜单打开图片查看器，选择服务端路径中的图片文件；也可以从文件管理器中以「打开方式」启动。

> 图片数据由客户端渲染，服务端只负责读取文件字节。
