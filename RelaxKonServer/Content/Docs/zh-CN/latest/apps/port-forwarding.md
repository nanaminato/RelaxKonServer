# 端口转发

端口转发（Port Forwarding）在本机建立 SSH 本地转发隧道，把服务端侧的服务映射到 `127.0.0.1`。

## 功能

- 优先绑定请求的端口，冲突时自动选择可用的 loopback 端口
- 返回实际可用的本地链接
- 运行中隧道列表、更新与停止
- 供浏览器或第一方服务请求使用

## 使用方式

1. 打开端口转发应用
2. 选择目标主机与远端端口
3. 复制生成的 `http://127.0.0.1:<port>` 链接
4. 在浏览器中打开该链接

## 与工作区的关系

端口转发的 SSH 设置与运行中的隧道**只保存在客户端本机**，不参与工作区同步。这是刻意的设计：隧道绑定的是这台设备到服务端的网络路径。

## 安全

- 隧道仅监听 `127.0.0.1`，不会暴露到局域网
- 使用宿主 SSH 凭据，RelaxKonOS 不额外保存密钥
