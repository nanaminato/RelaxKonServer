# 文件管理器

> 本页说明当前源码能力；发布包内容见[发行说明](/releases/0.1.2)，验收状态见相关实现文档。

文件管理器（Explorer）用于浏览和管理服务器上的文件，操作范围由服务器账户的权限决定。

## 实操：找到目录并上传一个文件

1. 确认当前连接：Server 工作区操作的是服务端文件，SSH 桌面使用 SFTP。先核对主机与账号，再从开始菜单打开文件管理器。
2. 用导航树或地址栏进入允许访问的目标目录，检查路径和列表。先选择测试目录，不直接在系统目录试验。
3. 新建一个测试文件夹并进入；上传前检查目标是否已有同名文件，按界面确认冲突处理。
4. 选择本机的小文件上传，等待传输与提交结束，再刷新列表核对名称和大小。不要只看到进度 100% 就认为文件已提交。
5. 选中上传文件执行下载，在本机核对可打开且内容正确。重命名、复制或移动前先检查选中项与目标路径。

读取被拒绝时查看身份与路径授权，不将“无权访问”当成空目录。Linux 用户模式限制在当前 Unix home；Windows 个人模式的助手受安装审阅范围约束。删除前逐项检查选中内容，本教程不承诺回收站或可恢复删除。大文件中断的处理见[传输教程](/docs/zh-CN/latest/apps/file-transfers)。

## 概述

界面移植自 Jaya File Manager。在 RelaxKonOS Server 工作区中，所有文件操作都通过服务端 REST API（`/api/v1.0/files/*`）执行，并沿用已登录服务器用户的权限，不额外建立一套 ACL。SSH 桌面则使用专用 SFTP 文件浏览器；它只限于已确认的 SSH 连接，不会调用 RelaxKonOS Server API。

## 功能

- 导航树（懒加载）+ 网格视图 + 地址栏 + 工具栏 + 状态栏
- 浏览、新建文件夹、删除、重命名、复制、移动
- 上传与下载
- 文件 / 目录属性查看，Linux 下可编辑 POSIX 权限
- 依据应用 manifest 的扩展名声明进行「默认打开」或「打开方式」
- 随主题切换的矢量图标：图标跟随浅色 / 深色外观变化，在高分屏下保持锐利

## 使用方式

从开始菜单打开文件管理器，双击目录进入，双击文件按声明方式打开。删除等危险操作会弹出确认对话框。

## 权限与安全

文件操作受服务器身份和路径权限约束；拒绝读取会显示无权访问，不作为空目录。系统模式中的受保护目录可通过精确文件授权与固定 Helper 访问，权限过期需要重新确认。Linux 用户模式限制在当前 Unix home，不能提权。不要通过把 Server 改为 root/管理员来解决权限问题。

系统模式中，受保护文件夹的读取授权有效期为 5 分钟，并绑定当前登录令牌。授权覆盖该文件夹的子目录和文件，期间浏览子目录或打开其中的图片无需重复输入管理员凭据；单个文件授权仅覆盖该文件。其他文件夹不在授权范围内，写入和删除仍另行授权，退出登录会撤销授权。
