# 记事本

记事本是面向纯文本的轻量编辑器，主要解决**跨平台文本编码**问题。

## 功能

- 打开与保存远端文本文件
- 多编码支持：UTF-8、GBK、Shift-JIS 等
- 编码选择对话框与代码编辑器共用
- 支持多窗口

## 使用方式

从开始菜单打开记事本，通过「打开」选择服务端路径。若文件编码与预期不符，可在编码对话框中选择正确编码后重新读取。
