# 应用安装器

应用安装器（App Installer）负责安装与更新 RelaxKonOS 应用包。它把外部应用纳入与内置应用相同的运行时、窗口管理与权限模型，同时**保留用户的审阅环节**。

## 概览

应用包是一个归档文件，其中包含清单与程序集，也可以携带自己的语言资源与图标。安装器负责安全解压、版本化安装，并把包登记到统一的软件包目录中，此后由外壳发现该应用。

## 适用场景

- 分发自己开发的应用：使用开发者 CLI 打包为应用包后交给安装器安装。
- 安装外置桌面外壳，用来替换默认的桌面呈现方式（它只会运行在 RelaxKonOS 主窗口内，**不会也不能替换宿主操作系统的桌面**）。
- 从文件管理器中直接打开一个应用包，交给安装器处理。

## 当前能力

- 从本机选择应用包安装，或从服务端文件系统中挑选应用包（会先在本机暂存以便审阅）。
- 安装与更新：同一应用的新版本以版本化目录安装，而不是就地覆盖。
- 与文件管理器集成：双击应用包即以「打开方式」交给安装器。
- 应用包自带本地化文件，并跟随工作区语言切换。
- 软件包目录是应用发现的唯一来源，安装器负责登记。

## 权限与安全

- **`v2` 的应用包没有签名，也没有沙箱。** 安装器只做安全解压与登记，**不会**为你验证包的来源或限制它能做什么。请只安装你信任或自己构建的包。
- 清单声明权限模型版本与包类型；缺失或不兼容的包不会被激活。
- 归档解压有边界限制，拒绝越界路径与其他不安全条目。
- 应用通过外壳提供的上下文请求操作，而不是直接访问服务容器、认证会话或远程文件接口。

## 平台差异

安装器与包格式在 Windows 与 Linux 上一致；差异体现在应用自身如何使用宿主能力。

## 已知限制

- **安装不等于可信**：由于没有签名与沙箱，安装一个包等同于信任它的作者。当前界面不会把「已安装」表述为「已审核」。
- 桌面外壳包只有在用户于个性化页面明确选择后才会加载；不兼容或初始化失败时保持当前桌面可用，并回退到默认桌面，工作区中的选择意图不会被覆盖。
- 包缺失、不兼容、被禁用或初始化超时时，不会导致桌面不可用。
