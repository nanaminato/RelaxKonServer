# 欢迎页

Welcome 是 RelaxKonOS 启动后最先打开的应用。它同时承担「引导」与「自检」两个职责。

## 概述

欢迎页会确认应用运行时（Runtime）、窗口管理器（Window Manager）与服务端连接是否正常，并给出下一步入口。

## 功能

- 显示客户端与服务端的连接状态
- 验证应用运行时与窗口管理器是否可用
- 提供文档、设置与示例应用的入口

## 使用方式

启动客户端后欢迎页会自动打开。关闭后可从开始菜单重新打开。
