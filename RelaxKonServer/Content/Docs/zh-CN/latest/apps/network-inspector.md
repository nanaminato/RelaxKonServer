# 网络诊断器

网络诊断器（Network Inspector）是由 RelaxKonOS 外壳直接拥有的**系统调试窗口**：它用很低的常驻成本查看 **RelaxKonOS 客户端到 RelaxKonOS 服务端**的调用。它参考开发者工具的网络面板，但不试图成为通用抓包器。

它**不是内置应用**，也不需要安装，不出现在应用列表中，也不向外部应用开放该能力。

## 概览

采用的信任边界是「系统窗口、宿主采集」：采集器是客户端宿主中的单例，负责内存上限、脱敏、分类与事件订阅；检查器窗口只读取它已经脱敏后的事件流。

默认**不录制**。只有当开发模式已开启且用户主动开始录制时才采集；停止录制、关闭开发模式或登出都会立即清空内存中的记录。

## 打开方式

| 入口 | 行为 |
| --- | --- |
| 设置 → 开发者 → 网络诊断器 | 显示状态与打开入口；开发模式关闭时说明原因并禁用 |
| `Ctrl+Shift+I` | 由主窗口的隧道路由处理，不依赖当前子窗口是否有焦点 |

## 监视范围

| 项目 | 是否包含 |
| --- | --- |
| RelaxKonOS 的 REST 调用（登录、设置、文件、浏览器数据、任务管理、能力令牌等） | 包含 |
| 终端集线器的连接、协商、调用结果与连接状态 | 包含 |
| 下载、上传、媒体播放 | 只保留摘要，不保存正文 |
| 请求与响应正文 | 可选的小型预览，严格脱敏与截断 |
| 网页视图中的网站流量、第三方组件的任意出站流量、服务器侧内部请求 | 排除 |
| 集线器消息帧、终端输入输出、底层套接字载荷 | 排除 |

「全部调用」指的是纳入该受控通信边界的 RelaxKonOS 接口调用，而不是整台设备的网络流量。

## 当前能力

- 筛选：文本、状态码、类型与来源。
- 详情：概览、请求、响应与时间线四个页签；媒体记录只显示结果摘要与安全标头。
- 记录保留：环形缓冲固定为有限条数与估算负载，任一上限先到即淘汰最旧条目，不写盘、不上传。
- 颜色仅作辅助，同时显示文本状态，保证主题与无障碍可用。

## 权限与安全

开始录制需要同时满足：开发模式开启、调用包已安装、拥有本地用户批准的权限、当前仍在认证会话中。任一前提不满足即停止、清空并通知订阅者，因此已打开的外部窗口不能在权限撤销后继续读取旧的敏感记录。

- 认证头、Cookie、含敏感名称的标头与字段、以及地址中同名的查询参数都会被替换为已脱敏占位符。
- 媒体、二进制与流式响应**永不读取或缓冲正文**，只记录方法、净化后的路径、成功或失败、状态码、耗时与内容类型。
- 取消与网络异常同样记为一条事件，只保留异常类别与受限的安全说明，不原样保存异常文本。

## 平台差异

无平台差异，行为只取决于客户端宿主。

## 已知限制

- 不捕获网页视图中的流量、第三方组件自行创建的客户端流量，或宿主其他进程的流量。
- 不记录集线器消息帧与终端字节。因此它能回答「连接是否建立、调用是否失败」，但不能用于还原终端会话内容。
- 不提供请求重放、编辑、阻断，也不导出抓包文件。
- 终端连接当前未启用自动重连，因此断开后界面只提示需要重新打开终端，不显示重连时间线。
